# Ferretería App

## Product Vision
A comprehensive web application for managing a hardware store. It features modules for inventory control, Point of Sale (POS) sales, purchase invoices, and financial balances. The system is built with Python and Flask, utilizing PostgreSQL for robust data storage and HTMX for a dynamic user experience. It offers a complete operational workflow from product management to detailed financial tracking and auditing.

## Key Features
- **Inventory Management**: Track products, categories, units of measure, and stock levels.
- **Point of Sale (POS)**: Manage sales transactions, shopping carts, and real-time stock deduction.
- **Purchase Invoices**: Handle supplier invoices, automate stock increase, and process invoice payments.
- **Financial Balance**: Comprehensive view of income, expenses, and net balance with detailed ledger.
- **Security**: Password-protected access.
